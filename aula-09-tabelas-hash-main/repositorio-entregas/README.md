## Como entregar

As entregas são feitas por pull request. O passo a passo com os comandos está
em [GUIA_PULL_REQUEST.md](GUIA_PULL_REQUEST.md).

Em resumo: faça um fork deste repositório, crie uma pasta com o seu nome,
coloque os arquivos dentro dela, faça commit e abra o pull request.

## Organização das pastas

Cada aluno tem uma pasta com o próprio nome, e dentro dela uma pasta por aula:

```
seu-nome/
    aula-07-recursao/
        exercicio01_contagem_regressiva.cpp
        exercicio02_contagem_crescente.cpp
        ...
```

Use o nome em letras minúsculas e sem acento, separando as palavras por hífen.
Mantenha sempre o mesmo nome de pasta ao longo do semestre.

A pasta `exemplo-nome-do-aluno` mostra a estrutura esperada.

## Regras

Mexa apenas na sua pasta. Não altere arquivos de colegas nem os arquivos da
raiz do repositório.

O título do pull request deve trazer o seu nome e a aula. Por exemplo:
`Maria Silva - Aula 07`.

Os enunciados dos exercícios ficam no repositório da disciplina, não aqui.
